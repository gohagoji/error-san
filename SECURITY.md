# Security Policy

## Supported Versions

`error-san` is currently in pre-1.0 development. Security updates are provided
for the latest published release only. Please upgrade to the latest version
before reporting or verifying a vulnerability.

| Version                  | Supported          |
| ------------------------ | ------------------ |
| Latest published release | :white_check_mark: |
| Earlier releases         | :x:                |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in `error-san`, please
report it privately through the repository's
[Security page](https://github.com/gohagoji/error-san/security) by selecting
**Report a vulnerability**. Please do not open a public issue or discussion.

Include as much detail as you can, such as:

- the affected version;
- a description of the vulnerability and its potential impact;
- steps to reproduce it or a minimal proof of concept; and
- any suggested mitigation, if known.

We aim to review reports as availability allows and communicate through GitHub's
private vulnerability reporting system.

Thank you for helping keep `error-san` and its users safe.
